# Session logs

Distilled summaries of substantial working sessions — the continuity layer
between conversations. Each file is `YYYY-MM-DD-<kebab-topic>.md`, 30–80
lines: context, what was done, key decisions, open questions, next steps.

Rules:

- **Distillate, not transcript.** Pointers + decisions + next-actions.
- **Link, don't duplicate** — commits by hash, specs/ADRs by path.
- **Immutable** — amend by adding a new dated file (`-2` suffix), never by
  editing an existing log.
- Written at the end of any session that shipped a commit chain or made a
  load-bearing decision. Quick one-shot fixes don't need one.

Start a new session by reading the most recent 1–2 logs here.
